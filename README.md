# Minigaraget

Övning 9 — en liten React-app för att parkera och ta bort fordon i ett garage.

Byggd med React 19, TypeScript, Vite och Tailwind CSS 4.

## Kom igång

```bash
npm install
npm run dev
```

Appen körs sedan på den adress Vite skriver ut (vanligtvis http://localhost:5173).

## Scripts

| Kommando          | Beskrivning                         |
| ----------------- | ----------------------------------- |
| `npm run dev`     | Startar utvecklingsservern med HMR  |
| `npm run build`   | Typkollar och bygger till `dist/`   |
| `npm run preview` | Förhandsgranskar bygget lokalt      |
| `npm run lint`    | Kör ESLint                          |

## Funktioner

- Lägga till fordon med regnummer och märke
- Ta bort fordon ur garaget
- Enkel validering med felmeddelande
- Räknare för antal parkerade fordon
